    About the data

    • Source: Open-Meteo hourly weather data, aggregated per local day.
    • Weather model: Open-Meteo's best match, which combines the most suitable weather models for each location, favouring high-resolution regional models where available.
    • Temperature at each altitude: each altitude uses a nearby model grid cell, whose elevation is shown on each card. Its 2 m temperature is corrected to the selected altitude with a lapse-rate (temperature-vs-height) adjustment; Village uses each site's own village altitude.
    • Precipitation and cloud cover: precipitation, its rain/snow split and cloud cover are not adjusted to the selected altitude: they refer to the weather model grid cell's elevation.
